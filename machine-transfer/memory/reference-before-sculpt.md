Before sculpting a new monster, boss, VFX, character, or any other model, ask the user for reference images and give prompts. The user generates them.

**Why:** the user wants to reduce guessing. The dragon's face and effects improved most once built from references.

**How to apply:** give prompts first and wait for images, unless the user says to go ahead. Study crops before building. See [[voxel-game-workflow]].
