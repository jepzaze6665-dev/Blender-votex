# ตารางเวลา VFX

มาตรฐาน: **Stylized Voxel Magic** โดย 3D voxel เป็นตัวเล่าเรื่อง และ 2D ใช้เน้นจังหวะเท่านั้น

เวลาเป็นวินาที นับจากกดสกิล ตารางนี้เป็นแผนการเติม 2D ทีละชิ้น ตอนนี้ใส่จริงเฉพาะ Winter Eclipse ส่วนชั้นอื่นต้องทดสอบก่อนใช้

## Frost Crescent
| เวลา | ตัวเด่น | ชั้น 2D | ความแรง | หมายเหตุ |
|---|---|---|---|---|
| 0.00–0.14 | ท่าฟัน | ไม่มี | - | ให้ผู้เล่นเห็นการง้าง |
| 0.14–0.29 | คลื่น 3D เริ่มพุ่ง | `speed` | 0.45 | โผล่สั้นตามหลังคลื่น |
| 0.29–0.70 | คลื่น 3D | ไม่มี | - | ให้เห็นทรงเต็ม |
| 0.70–1.40 | เศษและพื้น | `trail` | 0.30 | รอยจางบนพื้น |

## Winter Eclipse
| เวลา | ตัวเด่น | ชั้น 2D | ความแรง | หมายเหตุ |
|---|---|---|---|---|
| 0.00–1.37 | ดวงจันทร์ 3D | ไม่มี | - | จอมืดลง |

## กฎตรวจ
- ทุกสกิลต้องปิด 2D แล้วยังอ่านทรงได้
- แต่ละช่วงมีตัวเด่นเดียว และมี 2D ไม่เกิน 2 ชั้น
- ถ้าเติมชั้นใดแล้วไม่ดีขึ้น ให้เอาออก
- ตรวจบนลานสว่างและกล้องมุมกว้างจริง
